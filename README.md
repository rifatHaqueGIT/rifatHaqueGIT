- [📄 Resume Intelligence Dashboard (ResumeFinder)](https://github.com/rifatHaqueGIT/ResumeFinder)

    **Python, FastAPI, Next.js, TypeScript, Tailwind CSS, PostgreSQL, pgvector, Ollama, RAG**

  * Built a full-stack, AI-powered hiring analytics and **ATS optimization** platform that indexes, scores, and audits resumes against four engineering tracks (Software Engineer, Data Scientist/ML Engineer, DevOps/Cloud, Full Stack) using role-specific keyword weights and heuristics.
  * Engineered a **RAG** pipeline with **pgvector** semantic search and a local **Ollama** LLM (`llama3.1:8b`) that powers an AI career advisor chat and a job description matcher, which ranks which resume best fits a pasted posting and returns a targeted gap analysis.
  * Developed a **FastAPI** backend with **SQLAlchemy** models and a multi-format ingestion service (`.pdf`, `.docx`, `.txt`) featuring **SHA-256 deduplication**, document chunking, and embedding generation (`nomic-embed-text`).
  * Designed a dense, dark-themed **Next.js/TypeScript** dashboard with a resume inspector, role deep dives, a cross-resume **keyword gap heatmap**, and hiring-manager-style optimization tips, running fully local for privacy.

- [💇 HairAPP: Hair Type Classifier](https://github.com/rifatHaqueGIT/HairTypeDetect)

    **Python, PyTorch, EfficientNet-B0, OpenCV, MLflow, Databricks**

  * Built a computer vision classifier that identifies hair types (Type 1 to 4: Straight, Wavy, Curly, Kinky) from photos or a **live webcam feed**, using **transfer learning** on an ImageNet-pretrained **EfficientNet-B0** with a custom classification head.
  * Designed a full training pipeline with **early stopping**, **cosine learning-rate scheduling**, checkpointing, and per-class precision/recall/F1 evaluation with confusion matrices.
  * Integrated **MLflow** experiment tracking for parameters, metrics, and artifacts, and added **Databricks DBFS** sync with incremental dataset uploads for cloud-based training.
  * Created a **user data contribution pipeline** (submit, review, accept/reject/relabel, merge) so the dataset can grow over time and the model can be retrained on community-labeled images.
